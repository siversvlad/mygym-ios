# MyGym iOS 6.17 — сборка в Codemagic

## Подготовка с Windows
1. Откройте https://github.com/new и создайте **отдельный** репозиторий `mygym-ios` (не заменяйте действующий `mygym` с GitHub Pages).
2. Распакуйте этот архив. Загрузите в корень нового репозитория `codemagic.yaml`, `project.yml`, каталог `MyGym` и остальные файлы. Убедитесь, что `MyGym/Web/index.html` находится внутри каталога.
3. Откройте https://codemagic.io/, войдите через GitHub, разрешите доступ к `mygym-ios`, выберите **Add application** и этот репозиторий.
4. Выберите конфигурацию **Codemagic YAML**, workflow `ios-check`, нажмите **Start new build**.
5. Если сборка пройдёт, это подтвердит лишь компиляцию для симулятора. Файл `.app` из этого workflow **нельзя установить на обычный iPhone**.

## Следующий этап: установка на iPhone
Нужны подпись iOS-приложения и профиль provisioning. Для TestFlight обычно требуется платная программа Apple Developer. Не публикуйте сертификаты и приватные ключи в GitHub. Настройка подписанной сборки делается отдельно после успешной проверки компиляции.

## Ограничения прототипа
Это **не протестированная на iPhone** версия. BLE работает только с устройствами, которые транслируют стандартный Heart Rate Service 0x180D. Надёжный сбор пульса при блокировке экрана и импорт истории требуют доработки. Сначала экспортируйте резервную копию из веб-версии MyGym. Не удаляйте её.
