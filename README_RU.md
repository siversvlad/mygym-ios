# MyGym iOS — стартовый проект 6.17

Это **исходники нативного приложения**, не готовый IPA. Для сборки нужен Mac с Xcode (Windows не поддерживает сборку iOS-приложений напрямую). Установите XcodeGen (`brew install xcodegen`), в каталоге проекта выполните `xcodegen generate`, откройте `MyGym.xcodeproj`, выберите Team в Signing & Capabilities и запустите на физическом iPhone. На симуляторе Bluetooth не проверить.

Встроен существующий интерфейс MyGym в WKWebView и CoreBluetooth мост для стандартного BLE Heart Rate Service 0x180D / Heart Rate Measurement 0x2A37. Нестандартные/закрытые протоколы браслетов не поддерживаются. Подключение выбирает первое найденное совместимое устройство — в дальнейшем потребуется список выбора и повторное подключение.

**Важно о данных:** это новая песочница приложения. Данные из Safari/PWA автоматически не появятся. Перед установкой экспортируйте JSON в старом MyGym и импортируйте его в новую версию через раздел «Резервная копия». Проверить импорт в WKWebView на устройстве; функция скачивания JSON может потребовать нативный файловый мост.

Калории: при достаточном покрытии пульсом (не менее 70% времени и 30 измерений) и заполненных возрасте (18–65), поле и весе — эмпирическая формула Keytel et al. (2005). Для силовых нагрузок она может давать существенную ошибку. При нехватке данных используется прежняя оценка MET. Показывается источник расчёта в истории. Пульс пока хранится только в памяти и может потеряться при выгрузке приложения из памяти; это прототип, не проверенный на iPhone.

**Ограничения:** фоновый Bluetooth и надёжное сохранение данных во время блокировки iPhone ещё не реализованы; приложение должно оставаться активным. Нет автоматического чтения калорий, вычисленных самим браслетом. Прежде чем пользоваться ежедневно, нужно протестировать на реальном устройстве и добавить надёжное сохранение пульса/истории и импорт-экспорт через системные диалоги.
